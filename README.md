# 팀원 특근 신청 및 관리 시스템 (Smart Overtime System)

스마트폰 모바일 및 PC 브라우저에서 팀원들의 특근(초과근무)을 간편하게 신청하고, 관리자가 실시간 확인(승인) 및 엑셀 출력, 권한 관리를 통합 수행할 수 있는 웹 기반 솔루션입니다.

## 🆕 v1.49 최신 업데이트 내역 (2026-09-22)
1. **코드 자동 스냅샷 백업 시스템 (`data/code_backups/`)**:
   - 버전 업데이트 및 대규모 소스 수정 시 소스 코드 스냅샷이 자동으로 백업되어 원클릭 롤백 지원
2. **원클릭 복수 팀 필터링 지원**:
   - 부서 현황 카드 및 부서 칩 클릭 시 여러 팀을 다중 선택하여 통합 필터링 제공 (월간 캘린더, 리스트 뷰, 팀원 명부, 정산표 동시 적용)
3. **`📄 전체 특근 관리` 탭 메인 액션 바 `📥 엑셀 가져오기` 신설**:
   - `📤 엑셀(.xlsx) 내보내기` 버튼 바로 옆에 가져오기 버튼 배치
   - 내보내기 첫 번째 시트(`휴일일자별_특근현황`) 자동 파싱 및 DB(`overtimes`) 직접 갱신/등록
4. **선택된 부서 완전 격리 & 중복 필터링**:
   - 선택된 부서의 데이터만 가져오거나 갱신하며, 선택되지 않은 타 부서의 정보는 100% 보존
   - 동일 사원/동일 날짜/동일 구분의 기록은 중복 생성을 방지하여 DB 무결성 유지
5. **가져오기 결과 및 상세 오류/제외 로그 알림 모달**:
   - 총 읽은 행 수, 신규 생성, 기존 갱신, 타부서 제외 건수 및 행별 실패/오류 사유 상세 리포트 제공
6. **공식 매뉴얼 v1.49 업데이트**:
   - 사용자용, 관리자용, 시스템 통합본 PPTX 매뉴얼 3종 최신 개정 및 자동 동기화

## 📋 이전 릴리즈 내역 (v1.42)
1. **최종 실특근일 공식 전면 표준화**:
   - `최종 실특근 = 일반특근 - 사전차감 - (대체휴무 - 대체휴무 시 작성한 출장기간 이내의 사전차감)`
   - `사전차감 잔여수 = 총 사전차감 - 출장기간 내 사전차감`
2. **캘린더 날짜 디폴트 선택 연동**: 사원/관리자 캘린더 일자 클릭 시 특근 신청/대리 신청 폼에 해당 날짜 기본 세팅
3. **팀원 대리신청 대상자 필터링**: 슈퍼관리자(`ps37082`) 제외 전 팀원 정상 노출
4. **관리자 캘린더 대체휴무 시각화**: `🌿 대체휴무` 범례 뱃지 및 에메랄드 전용 칩(`.worker-chip.대체휴무`)
5. **항목별 사용자 맞춤 색상 설정 (Color Picker)**: 일반/법정/대체근무/대체휴무/사전차감/보너스 색상 변경 및 영구 저장
6. **DB 저장/기록 버튼 진행 피드백**: 로딩 스피너 및 '저장 중...', '등록 중...' 문구와 중복 클릭 방지
7. **리스트 사전차감 원클릭 토글 스위치**: 작업자 테이블 및 전체 특근 목록에서 즉시 토글
8. **관리자 특근 통계 개편**: 최근 3개월(7/8/9월), 1~4분기, 상/하반기, 연도별 집계 및 사전차감 잔여수 제공
9. **엑셀 정산표 고도화**: 상단 취합 기간/출력 일시 명기 및 헤더 셀제목 수식 안내 표기

## 🌟 주요 기능

1. **모바일 최적화 웹 UI**:
   - 스마트폰 화면 터치 및 PC 대화면 모두에 최적화된 모던 반응형 디자인.
   - 드래그 및 클릭으로 손쉽게 기간을 지정할 수 있는 스마트 인터랙티브 달력(캘린더).
2. **사번 기반 원터치 입장 & 자동 등록**:
   - 복잡한 회원가입 없이 본인의 사원번호 입력만으로 즉시 입장.
   - 미등록 사번인 경우 자동으로 정보 입력 팝업이 나타나 즉시 가입 가능.
   - 최근 접속 사번 로컬 브라우저 기억 기능 제공.
3. **사용자 모드**:
   - 본인 프로필(사번, 이름, 소속팀, 직급) 표시.
   - 특근 신청: 특근 분류(`대체근무` / `일반휴일` / `법정휴일`), 기간(달력 선택), 프로젝트 번호, 근무 장소, 상세 사유 기재.
   - 본인 신청 내역 카드 리스트: 관리자 확인 상태(`대기중` / `확인완료`) 실시간 표시.
   - 수정 및 삭제 기능과 변경 이력(Audit Log) 타임라인 보존.
4. **관리자 모드 (슈퍼관리자: `ps37082`)**:
   - 별도 관리자 화면 전환 버튼 제공.
   - 전체 팀원 특근 내역 일괄 열람 / 수정 / 추가 / 삭제.
   - **원클릭 확인(승인) 토글 스위치** 및 다중 선택 일괄 승인 지원.
   - 다차원 필터링: 기간, 소속팀, 특근 분류, 승인 상태, 사번/이름 검색.
   - **다중 선택 / 전체 선택 후 서식 완비 엑셀(.xlsx) 내보내기**.
   - 팀원 명부 관리 및 일반 팀원에게 "관리자 권한" 부여/회수.
   - 슈퍼관리자 계정(`ps37082`) 보호 (삭제 및 권한 박탈 방지).
5. **외부 환경 및 모바일 원격 접속 지원**:
   - **사내 동일 Wi-Fi**: 로컬 IP 접속 및 화면 상단 `📱 모바일 접속 QR` 코드로 카메라 스캔 즉시 접속.
   - **사외 인터넷/LTE/노트북**: `start_external_access.bat` 실행으로 보안 공용 HTTPS 주소(`https://xxxx.trycloudflare.com`) 즉시 발급.
   - 모바일 브라우저 [홈 화면에 추가] 시 앱처럼 원클릭 사용 가능.
6. **데이터 절대 무소실 (Data Integrity)**:
   - SQLite WAL (Write-Ahead Logging) 모드 적용.
   - `data/overtime.db` 독립 분리 구조로 프로그램 코드 업데이트 시에도 데이터 영구 보존.
   - 서버 기동 시 `data/backups/`에 타임스탬프 스냅샷 자동 백업.
7. **사용 방법 PPT 매뉴얼 제공**:
   - 전 과정이 상세히 기술된 16:9 와이드스크린 프레젠테이션 파일(`Overtime_System_Manual.pptx`) 내장 및 웹 상단에서 원클릭 다운로드.

## 🚀 실행 방법

### 1. 시스템 서버 실행
`start_server.bat`을 더블 클릭하여 실행합니다.
- 외부망 접속 지원을 위해 `start_external_access.bat`(Cloudflare 터널)을 함께 실행합니다.

### 2. 외부 접속망(LTE / 5G / 자택 / PC) 접속 안내
- **외부 보안 링크 접속**: `https://xxxx.trycloudflare.com` (관리자가 공유한 HTTPS 링크)
- **스마트폰 모바일 접속**: 화면 상단 `📱 모바일 접속 QR`을 스마트폰 기본 카메라로 스캔하여 LTE/5G 어디서나 간편 접속
- **전용 앱처럼 쓰기**: 모바일 브라우저 메뉴에서 `[홈 화면에 추가]`를 터치하면 스마트폰 바탕화면 앱으로 등록됩니다.
